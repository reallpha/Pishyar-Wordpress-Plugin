## معرفی افزونه پیشیار

**پیشیار** افزونه‌ای برای **شخصی‌سازی، برندینگ و مدیریت پنل مدیریت وردپرس** است. با این افزونه می‌توانید ظاهر پیشخوان، صفحه ورود، رنگ‌ها، فونت‌ها و منوهای مدیریتی را بدون نیاز به کدنویسی متناسب با نیاز و هویت برند خود تغییر دهید.

این افزونه با ترکیب امکانات شخصی‌سازی و ابزارهای مدیریتی، کار با پیشخوان وردپرس را ساده‌تر می‌کند. مدیریت نوار ادمین و دسترسی کاربران، بررسی وضعیت سلامت سایت، پشتیبان‌گیری از تنظیمات و سازگاری با ووکامرس و المنتور، بخشی از قابلیت‌های آن هستند.

> **توسعه‌داده‌شده توسط:** محمدرضا چنگیزی  
> **وب‌سایت شخصی:** وب ویژن  
> **زبان:** فارسی و راست‌چین (RTL)

## هدف این ریپازیتوری

این ریپازیتوری **فقط برای نمایش HTML پیش‌نمایش** افزونه پیشیار ایجاد شده است. کد کامل و قابل نصب افزونه در این ریپازیتوری قرار ندارد و نسخه اصلی از طریق لینک راست‌چین قابل تهیه است.

- مشاهده ظاهر و ساختار پیش‌نمایش
- بررسی طراحی رابط کاربری
- آشنایی با بخش‌های مختلف افزونه

## قابلیت‌های افزونه

### شخصی‌سازی پیشخوان وردپرس
- تغییر رنگ تمامی بخش‌های پنل مدیریت
- بیش از ۳۰ پریست رنگی آماده
- ساخت رنگ‌بندی اختصاصی
- پیش‌نمایش زنده تغییرات
- پشتیبانی از بیش از ۷۰ فونت فارسی
- بارگذاری فونت اختصاصی
- تغییر فونت پیشخوان

### شخصی‌سازی صفحه ورود
- تغییر لوگوی پیشخوان
- تغییر لوگوی صفحه ورود
- شخصی‌سازی نوار ادمین
- شخصی‌سازی فوتر پیشخوان
- تغییر فاوآیکون پیشخوان

### مدیریت منوها و دسترسی‌ها
- مدیریت منوهای پیشخوان
- مخفی‌سازی منوها بر اساس نقش کاربران
- مدیریت دسترسی کاربران
- تنظیمات اختصاصی برای هر نقش کاربری

### ظاهر و تم
- حالت روشن و تیره
- زمان‌بندی خودکار پریست‌ها

### داشبورد مدیریتی
- نمایش اطلاعات وردپرس
- بررسی سلامت سایت
- بررسی وضعیت سرور
- بررسی پایگاه داده
- بررسی فضای ذخیره‌سازی
- بررسی نسخه وردپرس
- بررسی نسخه PHP
- بررسی استانداردهای دسترسی‌پذیری (WCAG)
- نمایش مشکلات سایت
- ارائه پیشنهادهای بهینه‌سازی

### ابزارهای مدیریتی
- پاک‌سازی وردپرس
- ثبت تاریخچه تغییرات
- واردات و صادرات تنظیمات
- پشتیبانی از REST API

### سازگاری
- ووکامرس
- المنتور
- وردپرس چندسایتی (Multisite)
- قالب‌های استاندارد وردپرس
- افزونه‌های محبوب وردپرس

### سایر ویژگی‌ها
- رابط کاربری کاملاً فارسی
- بدون نیاز به کدنویسی
- عملکرد سبک و بهینه
- به‌روزرسانی آسان
- راهنمای داخلی افزونه
- پشتیبانی از آخرین نسخه‌های وردپرس و PHP
